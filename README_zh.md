# 超级回复 (Super Reply)

> 一款快速、优雅的 Windows 快捷短语管理工具。按下 `Alt+V`，在任意软件中快速粘贴预设短语。

## 功能

- **两级分组树** — 支持根分组 + 一级子分组，分组名旁显示短语数量
- **快捷粘贴** — 全局快捷键（默认 `Alt+V`）在光标处呼出短语面板，点击即粘贴
- **自适应布局** — 自动模式下无滚动条，短语超出纵向空间时自动分列显示
- **深色 / 浅色 / 跟随系统** — 三种主题，工具栏一键切换
- **导入 / 导出** — JSON 格式备份，方便跨设备迁移
- **快捷键自定义** — 支持单键（F1~F12）和组合键（Ctrl+Alt+X）
- **短语管理** — 右键分组即可添加/编辑/删除/置顶短语

## 快速开始

1. 从 [Releases](../../releases) 下载 `SuperReply.exe`
2. 双击运行（图标在系统托盘）
3. 按 `Alt+V` 呼出快捷短语面板
4. 右键分组 → **添加短语** 创建第一条常用语
5. 点击短语即可粘贴到当前输入框

## 使用说明

**管理窗口**（编辑短语的地方）：
- 左侧：分组树（右键创建/管理分组）
- 右侧：短语列表（双击编辑短语）
- 工具栏：主题切换、导入导出、设置、关于

**弹窗**（快捷键呼出）：
- 出现在光标位置，左侧分组树、右侧短语列表
- 鼠标悬停分组即可切换
- 点击短语粘贴，点击外部或 ESC 关闭

## 从源码构建

```bash
pip install -r requirements.txt
python main.py
```

打包 EXE：
```bash
pyinstaller --onefile --windowed --name "SuperReply" --icon=icon/icon.png main.py
```

## 项目结构

```
├── main.py              # 入口文件
├── src/
│   ├── db/              # SQLite 数据库层
│   ├── gui/             # PyQt5 界面（主窗口、弹窗、短语列表、分组树、主题）
│   ├── hotkey/          # 全局热键（Windows RegisterHotKey API）
│   └── locale.py        # 多语言（中/英/日）
├── Contact_Information/ # 作者联系方式
└── requirements.txt
```
